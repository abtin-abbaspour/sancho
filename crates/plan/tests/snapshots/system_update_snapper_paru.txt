[verified recipe · system.update v1] Update all installed packages, including AUR packages, then trim the package cache
Risk: HIGH — you will be asked to type "yes" to confirm

  1. Take a snapper snapshot so the update can be rolled back
     $ sudo snapper -c root create --cleanup-algorithm number --description 'sancho: before changes'
     nothing to undo

  2. Upgrade all packages from the official repositories
     $ sudo pacman -Syu
     can be undone only by rolling back the snapshot from step 1

  3. Upgrade AUR packages with paru
     $ paru -Sua
     can be undone only by rolling back the snapshot from step 1

  4. Delete cached package files older than the newest 2 versions
     $ sudo paccache -r -k 2
     CANNOT be undone

Skipped:
  - Take a system snapshot with Timeshift (needs snapshot_tool timeshift, this system has snapper)

Notes:
  - Arch does not support downgrading single packages; without a snapshot an upgrade cannot be undone.

Undo: some steps CANNOT be undone (see above)
